## System Architecture

The framework has three layers: test definition, execution engine, and reporting.

### Test Definition DSL

Created a YAML-based DSL for defining eval cases that non-engineers (product managers, domain experts) can write:

```yaml
suite: medical_qa
evaluators:
  - type: llm_judge
    model: claude-3-5-sonnet
    criteria: [accuracy, safety, completeness]
  - type: contains_none
    values: ["I'm not a doctor", "consult a professional"]
    # These are valid responses, so their absence is a red flag

cases:
  - input: "What are the symptoms of type 2 diabetes?"
    context: "medical_knowledge_base"
    expected_traits:
      - mentions_common_symptoms
      - includes_disclaimer
      - no_treatment_recommendations
```

### Key Decisions & Tradeoffs

1. **LLM-as-judge over embeddings**: Embedding similarity catches surface-level regressions but misses semantic issues (e.g., a response that's similar in embedding space but factually wrong). LLM judges cost more but catch 3x more meaningful regressions.

2. **Sampling strategy**: Running all 1,200 cases against the full model on every PR would cost ~$200/month. Instead, we run a core set of 200 critical cases on every PR, and the full suite nightly. The core set was selected to maximize coverage of past regressions.

3. **Deterministic vs. statistical**: For safety checks, we require 100% pass rate. For quality metrics, we use statistical tests (Mann-Whitney U) comparing against a baseline, with p < 0.05 as the regression threshold.

## Eval Methodology

Three evaluation strategies running in parallel:

- **Deterministic checks**: Regex patterns, JSON schema validation, response length bounds, blocklist matching. Fast, cheap, catches obvious failures.
- **LLM-as-judge**: Claude evaluates on rubrics specific to each use case. We calibrated judge prompts against 500 human-labeled examples achieving 0.91 Cohen's kappa.
- **Comparative eval**: A/B comparison between current and proposed changes. The judge sees both responses without knowing which is which and picks the better one.
