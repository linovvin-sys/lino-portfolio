## Features

- **Products**: add, edit and search items with category, price and quantity
- **Stock in / stock out**: every movement is recorded with date and quantity
- **Low-stock alerts**: items below their reorder level are highlighted
- **Reports**: current stock value and recent movements

## How it's built

A Python desktop app with a Tkinter interface and a MySQL database. Stock changes are written as movement records, and the current quantity is always derived from them, so the history and the totals can't disagree.

```python
def low_stock(cursor):
    cursor.execute(
        "SELECT name, quantity, reorder_level FROM products "
        "WHERE quantity <= reorder_level ORDER BY quantity"
    )
    return cursor.fetchall()
```
