## Features

- **Room management**: add rooms, set types and rates, and see live availability
- **Reservations**: book a room for a date range, with overlap checks to prevent double bookings
- **Check-in / check-out**: record guest arrivals and departures
- **Billing**: compute the total from the room rate and number of nights
- **Login**: staff accounts protected with sessions and hashed passwords

## How it's built

The app is written in native PHP with Bootstrap for the interface. Pages talk to MySQL through prepared statements to keep queries safe from SQL injection.

```php
$stmt = $conn->prepare(
  "SELECT COUNT(*) FROM reservations
   WHERE room_id = ? AND check_in < ? AND check_out > ?"
);
$stmt->bind_param("iss", $roomId, $checkOut, $checkIn);
```

## What I learned

- Structuring a PHP project without a framework: includes, sessions and form handling
- Writing safe SQL with prepared statements
- Building responsive layouts quickly with Bootstrap's grid and components
