## Features

- **Car list**: view every car with its model, plate number, daily rate and availability
- **Rent a car**: pick an available car, enter the customer's name and number of days
- **Return a car**: mark it available again and show the final bill
- **Saved records**: cars and rentals are written to files and loaded on startup

## How it's built

The program is organized around classes for cars and rentals, with a simple menu loop in `main()`.

```cpp
class Car {
public:
    std::string plate, model;
    double dailyRate;
    bool available = true;

    double rentalFee(int days) const { return dailyRate * days; }
};
```
