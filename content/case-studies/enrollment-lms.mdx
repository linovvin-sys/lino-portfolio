## Features

### Enrollment

- Online enrollment form with required documents
- Registrar dashboard to review, approve or reject enrollments
- Section assignment with capacity checks, so full sections can't be over-enrolled

### Learning management

- Teachers create classes, post lessons and upload materials
- Students see their classes, lessons and announcements in one place
- Grades are recorded by teachers and visible to each student

## How it's built

| Part | Technology |
|------|------------|
| Frontend | Bootstrap, JavaScript |
| Backend | Native PHP |
| Database | MySQL |
| Access control | Role-based permissions |

## What I learned

- Designing a relational schema for students, sections, subjects and grades
- Role-based access control, and why every check must happen on the server
- Structuring a larger native PHP app into reusable includes and shared layouts
